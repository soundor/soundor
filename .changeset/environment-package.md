New package: `@soundor/environment`, the types of Soundor's JavaScript environment for libraries. It contains `soundor:ui`, image and font imports, and exactly the Web globals the runtime provides. It is types only and is generated by core: a library adds it as a development dependency and sets `"types": ["@soundor/environment"]`. Its parts (`ui.d.ts`, `assets.d.ts`, `globals.d.ts`) can also be included separately, for a toolchain that declares image imports itself or code that also runs in a plain web page. `@soundor/core` no longer ships these declarations (`runtime/`). A new guide, "Writing a UI library", covers this.
