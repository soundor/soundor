The Web host's panel has a preset selector, as a DAW's program selector for the plugin's factory presets: it shows the selected preset (marked modified once its values change, or Custom), follows what the UI, the controller or History selects, and loads a preset without a History entry, as a host's program change does. Choosing the modified preset loads it again. It shows only when the config declares presets.
