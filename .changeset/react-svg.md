'@soundor/react': minor

Add the @soundor/react/svg subpath with Svg, G, Path, Circle, Rect, Ellipse, Line, Polygon and Polyline. React reconciles logical vector children and publishes atomic scenes only for affected roots; only Svg participates in layout. Includes inherited presentation, viewBox mapping, numeric geometry, transforms, root refs/events/accessibility, examples and documentation. Requires the SVG scene protocol in @soundor/engine 0.6.0 or later. The API shares the React package version and does not provide third-party icon-library compatibility.
