Styles follow React Native conventions: flexbox laid out by
[Yoga](https://www.yogalayout.dev), spacing shorthands, percentages, CSS
colors, rounded corners, opacity and transforms. The
[node components](/docs/components) take `style`. `Portal.Host` also takes
`style`; `Modal` takes `backdropStyle`. `Portal` and `FocusScope` have no
style of their own.

## Values

- **Lengths** are numbers, in logical pixels; CSS pixels (`'120px'`, kept as
  the number); or percentages of the parent (`'50%'`). Sizes, margins,
  positions and `flexBasis` also take `'auto'`.
- **Colors** are any CSS color: `'#rgb[a]'`, `'#rrggbb[aa]'`, `rgb()`,
  `hsl()`, a name, or `'transparent'`.
- **An invalid value throws** a `TypeError` naming the property.

## Layout

A view lays out its children with flexbox, as in React Native rather than
on the Web:

- **A column** by default (`flexDirection: 'column'`), children stretched
  across it (`alignItems: 'stretch'`).
- **No shrinking** unless asked: `flexShrink` is 0 by default. `flex: n`
  (n > 0) grows by n, shrinks, and starts from zero.
- **Spacing:** `margin`, `padding` and `borderWidth` with their
  `…Horizontal`, `…Vertical` and per-side forms; `gap`, `rowGap` and
  `columnGap` between children.
- **Position:** `position: 'absolute'` takes a node out of the flow, placed
  by `top`, `right`, `bottom`, `left` (or `inset`) in its parent's box.
- **Stacking:** `zIndex` (an integer) stacks a node among its siblings, for
  drawing and hit testing alike; layout keeps the tree's order.
- **Clipping and scrolling:** `overflow` ([Overflow](#overflow)).
- **Input:** `pointerEvents` lets the pointer through a node, its children,
  or both; `cursor` sets its shape ([Cursor](#cursor)).

Both runtimes lay a style out the same, with the same Yoga, given the same text
sizes; see
[Where layout differs](/docs/web-runtime#where-layout-differs).

## Overflow

`overflow` says what happens to children that reach past a box:

| Value                 | Clips | Scrolls                                                   |
| --------------------- | ----- | --------------------------------------------------------- |
| `'visible'` (default) | no    | no                                                        |
| `'hidden'`            | yes   | no                                                        |
| `'scroll'`            | yes   | yes: wheel, scrollbar, `scrollTo()`, with `scroll` events |

Any view scrolls with `'scroll'`, an [`Animated.View`](/docs/components/animated-view)
too ([Scrolling](/docs/components/view#scrolling)). It is the CSS meaning,
not React Native's, where `'scroll'` only clips.

```tsx
<Animated.View
  style={{ overflowY: 'scroll', height: 200 }}
  transition={{ type: 'spring' }}
>
  {rows}
</Animated.View>
```

- **One axis:** `overflowX` and `overflowY` take the same values, and win over
  `overflow` whatever the order. `{ overflowX: 'scroll' }` is a strip that
  scrolls sideways; `{ overflow: 'scroll', overflowX: 'hidden' }` only scrolls
  down.
- **Both clip or neither:** a box that scrolls clips both ways, so `'visible'`
  on one axis beside a clipping one clips too, as `'hidden'`, as in CSS.
- **Style arrays** merge key by key, so a later `overflow` does not undo an
  earlier `overflowX`, unlike a CSS shorthand: set both axes, or only
  `overflow`, to change them later.
- **Only a view's children scroll.** On a `Text`, an image or a canvas,
  `'scroll'` clips, as `'hidden'`; put long text in a view that scrolls.
- **Stopping:** a view whose style no longer scrolls an axis goes back to its
  start there, and fires `scroll`.
- **Scrollbars:** a view that scrolls draws thin indicators for the axes it
  scrolls, unless its `scrollIndicators` prop is `false`
  ([`useScrollbar`](/docs/hooks/use-scrollbar) draws your own).
- **From code:** the node's `scrollTo()`, `scrollBy()` and `scrollIntoView()`,
  smooth with `behavior: 'smooth'` ([Scrolling from code](/docs/components/view#scrolling-from-code)).

## Text

`fontFamily`, `fontSize`, `fontWeight`, `fontStyle`, `lineHeight`,
`letterSpacing`, `textAlign` and `color` style a [`Text`](/docs/components/text)
(and a [`TextInput`](/docs/components/text-input)'s text). `fontFamily` is a
bundled font registered with `registerFont`, or one installed on the system
([Fonts](/docs/components/text#fonts)).

## Paint and transforms

`backgroundColor`, `borderColor`, `borderRadius` (all corners, or each),
`opacity` (for the node and everything in it), and `transform`: an ordered
list of `translateX`, `translateY`, `scale`, `scaleX`, `scaleY` and `rotate`
(radians as a number, or `'90deg'`), about the node's centre. A transform
moves how the node is drawn and hit, not its layout;
[`Animated.View`](/docs/components/animated-view) animates it.

## Outline

`outlineWidth` draws a line around a node, as CSS's `outline`: outside its
border, following its `borderRadius`, `outlineOffset` away from it (inside
when negative), in `outlineColor` (black by default). Unlike a border it
takes no room and is not hit, so it can come and go without moving
anything: a focus ring
([Focus rings](/docs/components/events#focus-rings)).

```tsx
<View
  style={{
    borderRadius: 8,
    outlineWidth: 2,
    outlineOffset: 2,
    outlineColor: '#3a7bfd',
  }}
/>
```

Leave room for it: an ancestor with `overflow: 'hidden'` clips it, and in
the JUCE runtime a later sibling drawn over the same place covers it (a
browser draws outlines above).

## Cursor

<Snippet name="cursor" height={200} />

`cursor` sets the pointer's shape over a node and everything in it, until a
child sets its own. It is `'auto'` by default, which takes the parent's: the
arrow (`'default'`) at the root, whatever is drawn there, and the I-beam
(`'text'`) in a [`TextInput`](/docs/components/text-input). No component sets
one for you, buttons included, as in desktop apps and plugins; add
`cursor: 'pointer'` where you want the hand.

```tsx
<View style={{ cursor: 'ns-resize' }} onPointerDown={startDrag} />
```

While a pointer is pressed, the pressed node's cursor shows wherever it is
dragged, so a knob's stays on until release. `'none'` hides the pointer. The
shapes are those every platform has: `'default'`, `'none'`, `'pointer'`,
`'text'`, `'crosshair'`, `'move'`, `'ew-resize'`, `'ns-resize'`,
`'nesw-resize'` and `'nwse-resize'`.

## Combining styles

`style` takes arrays and falsy entries, merged in order (later wins), so a
condition can add a style:

```tsx
import { StyleSheet, View } from '@soundor/react';

const styles = StyleSheet.create({
  knob: { width: 48, height: 48, borderRadius: 24 },
  active: { backgroundColor: '#3a7bfd' },
});

<View style={[styles.knob, active && styles.active]} />;
```

`StyleSheet.create()` returns its styles as they are, typed, and
`StyleSheet.flatten()` merges a style prop into one object.
