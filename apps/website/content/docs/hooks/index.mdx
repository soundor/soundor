---
title: Hooks
description: The React hooks @soundor/react adds, for parameters, state, native streams, the host, presets, frames and the editor and view.
---

`@soundor/react` adds hooks for parameter and persistent-state values, native
streams, History actions, the host, factory presets, frames, the editor's and
view's size, visibility and focus, canvas sizes, scrollbars and presses.
React's hooks (`useState`, `useEffect`, `useRef`, …) work as everywhere else.
Each hook gives a Soundor concept as a value that re-renders the component
when it changes, so a component never subscribes to a `soundor:*` module
by hand.

| Hook                                                       | What it is for                                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------ |
| [`useParameter`](/docs/hooks/use-parameter)                | A parameter's value, re-rendering when it changes.                 |
| [`useStateValue`](/docs/hooks/use-state-value)             | A persistent field's immutable current value.                      |
| [`useNativeStream`](/docs/hooks/use-native-stream)         | A native stream's latest value, re-rendering when a newer arrives. |
| [`useHistory`](/docs/hooks/use-history)                    | Reactive undo/redo status and stable actions.                      |
| [`useHostState`](/docs/hooks/use-host-state)               | The host's sample rate, name, track and transport.                 |
| [`usePresetSelection`](/docs/hooks/use-preset-selection)   | The selected factory preset and whether it was modified.           |
| [`useAnimationFrame`](/docs/hooks/use-animation-frame)     | A callback before every frame, to draw a canvas or follow a value. |
| [`useViewSize`](/docs/hooks/use-view-size)                 | The view's size, re-rendering when the editor is resized.          |
| [`useEditorSize`](/docs/hooks/use-editor-size)             | The editor's own size and whether it can be resized.               |
| [`useEditorVisibility`](/docs/hooks/use-editor-visibility) | Whether the editor is shown, to pause work nobody sees.            |
| [`useEditorFocus`](/docs/hooks/use-editor-focus)           | Whether keyboard focus is within the editor.                       |
| [`useCanvasSize`](/docs/hooks/use-canvas-size)             | A canvas's buffer, exactly the device pixels its box covers.       |
| [`useScrollbar`](/docs/hooks/use-scrollbar)                | A scrollbar of your own, drawn however you like.                   |
| [`usePressable`](/docs/hooks/use-pressable)                | What `Pressable` does, for a component of your own.                |
