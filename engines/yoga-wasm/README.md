# @soundor/yoga-wasm

The Yoga that [`@soundor/engine`](https://soundor.dev/docs/engine) links, compiled to WebAssembly, so a plugin UI lays out the same in the browser as in a plugin. `@soundor/web-runtime` uses it; a plugin project does not need to install it.

- [Guide and reference](https://soundor.dev/docs/contribute/yoga-wasm)
- [Documentation](https://soundor.dev/docs)
